2020年5月に Switch で、同年11月に Steam 版、2022年3月に iOS/Android 版が発売された「UNREAL LIFE（アンリアルライフ）」の実績完全達成のための攻略ガイドを掲載します。

<!-- more -->

## はじめに

本攻略は、タイトルにも番外編と銘打っている通り、{% post_link guide-unreal-life-part1 '前編（＃０～＃３）' %}と{% post_link guide-unreal-life-part2 '後編（＃４～＃８）' %}の攻略を参考に、本編を最後までプレイした人のために書かれています。そのため、未プレイの方は全てのエンディングをひと通り見てからこの記事をご覧いただくよう、お願いします。

### 方針概要

おおまかには以下の手順で、前編及び後編の攻略で残った実績を全て達成する。それらの攻略にて言及済みの実績のうち、未達成のものがある場合は、そちらをすべて熟してから臨むこと。

1. タイトル画面で「＃３ 路地裏とワンちゃん」のセーブデータを選んでロードする。
2. 「＃３ 路地裏とワンちゃん」で、実績「特異点」を達成する。
3. 「＃４ 青い本」で、分岐用マニュアルセーブの準備と、実績「真実」「VOLTAの戦士」を達成する。
4. ストーリーを進め、エンディング「ある少女のアンリアルライフ」に到達して、実績「ある因果のエクセプション」を達成する。
5. 分岐用マニュアルセーブをロードして、「＃７ 最後の廊下」で、実績「不思議な猫」を達成する。

## 実績完全達成チャート

### ＃３ 路地裏とワンちゃん

セーブデータから「＃３ 路地裏とワンちゃん」のデータを選んでロードする。

#### １：路地裏

前編攻略と同じ手順で進む。

#### ２：幻想図書館

前編攻略の「２Ａ：エントランス・バルコニー」と「２Ｂ：書架・休憩室」は同じ手順で進めて、「２Ｃ：バルコニー・休憩室・書架」では手順２の後、書架に行かずに入口２階の転送ドアから、旅の宿「くじら」の【自分の部屋に戻る】。

#### 実績「特異点」

##### ロッカールーム

1. 自分の部屋からエレベーターでロビーに下り、従業員用の通路から外に出る。
2. 左端の小屋（ロッカールーム）に入り、カバンから【ロッカーのカギ】を取り出して、左奥のロッカーに【ロッカーのカギを使う】。ロッカーは超低確率で開錠する設定になっているので、成功するまで何度もコマンドを繰り返す。開錠に成功すると、実績「特異点」を達成。
3. 自分の部屋の転送ドアから幻想図書館に戻る。

#### ２：幻想図書館

前編攻略の「２Ｃ：バルコニー・休憩室・書架」の３以降と同じ手順を踏む。

### ＃４ 青い本

#### １：カフェテリア～絵の壁

後編攻略と同じ手順で進む。

#### ２：幻想美術館

後編攻略の「２Ａ：展示回廊・倉庫」は同じ手順で進めて、「２Ｂ：館外・展示回廊・館内・倉庫」では手順４の後、美術館長との会話イベントを見てから奥に進まずに引き返し、手前の転送ドアから旅の宿「くじら」の【自分の部屋に戻る】。

#### 実績「真実」「VOLTAの戦士」

##### ロッカールーム

{% message color:danger %}
マニュアルセーブは１つしかスロットがないため、実績「ある因果のエクセプション」と実績「不思議な猫」の両方を達成するまでは、ここで準備するデータを上書きしないように気を付けること。
{% endmessage %}

1. **自分の部屋に戻った後、奥のベッドで【マニュアルセーブする】。**
2. エレベーターでロビーに下り、従業員用の通路から外に出る。左端の小屋（ロッカールーム）に入り、左奥のロッカーの中に【入る】。
3. 色の付いた張り紙が見えるまでひたすら左奥へ進み、右から順に６枚の張り紙の【字を読む】。読み終わった後に手前へ引き返し、マリーらしきマリモと【お話しする】と、実績「真実」達成。
4. イベントシーンの後、旅の宿「くじら」の自分の部屋に戻されるので、転送ドアから【幻想美術館へ】向かう。

##### 幻想美術館（倉庫）・商店街・来客用の簡易駅・絵の壁

{% message color:info %}
１つ目以外の絵を描く時にキャンバスの前で【お絵描きブラシ】を２回使う理由は、前回の絵を消すためなので、手間でなければ移動前に消しても良い。そして、トクロの思い出す順で手順を組んでいるが、６種類の絵は同不順で描いても実績を達成できる。
{% endmessage %}

1. 転送ドア左横の非常口のマークを調べて【覚える】。その後、絵の壁へ向かう。トクロ左横の白いキャンバスの前で、カバンから【お絵描きブラシ】を取り出して使う。
2. 路地裏へ向かい、屋上に設置されているシャワーマシンの絵を調べて【覚える】。絵の壁へ行き、キャンバスに【お絵描きブラシ】を２回使う。
3. 商店街の給水所入口の絵を【覚える】。絵の壁のキャンバスに【お絵描きブラシ】を２回使う。
4. 旅の宿「くじら」の来客用の簡易駅へ向かい、電池を入れた何かの装置にある稲妻の絵を【覚える】。絵の壁へ行き、キャンバスに【お絵描きブラシ】を２回使う。
5. 再び商店街へ行き、給水所左横のお店の入口に貼られた魚の絵を【覚える】。絵の壁に戻り、キャンバスに【お絵描きブラシ】を２回使う。
6. 幻想美術館倉庫へ行き、赤い手のマークが描かれたポスターをキャンバスの右側から調べて【覚える】。絵の壁へ行き、キャンバスに【お絵描きブラシ】を２回使う。
7. トクロに【「ゲーム」について】尋ねると、実績「VOLTAの戦士」達成。

#### ２：幻想美術館倉庫

幻想美術館倉庫に戻って奥に進み、イベントを見る。

### ＃５ 旅立ち以降

「＃５ 旅立ち」～「＃８ 現実へ」を後編攻略と同じ手順で進み、エンディング「ある少女のアンリアルライフ」に到達すると、実績「ある因果のエクセプション」達成。

### 実績「不思議な猫」

#### ＃４ 青い本

事前に準備したマニュアルセーブをロードする。

##### ロッカールーム・幻想美術館倉庫

1. エレベーターでロビーに下り、従業員用の通路から外に出る。左端の小屋（ロッカールーム）に入り、左奥のロッカーの中に【入る】。
2. 突き当たりまでひたすら奥に進み、壁に当たったところで引き返し、何もせずにロッカーから出る。
3. 幻想美術館倉庫に戻ってから、奥に進んでイベントを見る。

#### ＃５ 旅立ち～＃６ 空飛ぶクジラ

後編攻略と同じ手順で進む。

#### ＃７ 最後の廊下

後編攻略の「１：学校」は同じ手順で進めて、「２：カフェテリア・職人の部屋・路地裏・魚の駅」では手順１で業務用エレベーターを使う前に、左奥の小屋（ロッカールーム）に入る。

##### ロッカールーム

{% message color:info %}
実績達成した後に続けるか辞めるかは、プレイヤーの判断に任せる。このまま続ける場合は、ロッカールームを出てから業務用エレベーターで【上に行く】。以降は、後編攻略と同じ手順で進めること。
{% endmessage %}

左奥のロッカーの中に【入る】。突き当たりまでひたすら奥に進んで、猫のようなカタチの「あんないにん」と【お話しする】と、実績「不思議な猫」達成。
