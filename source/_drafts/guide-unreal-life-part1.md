2020年5月に Switch で、同年11月に Steam 版、2022年3月に iOS/Android 版が発売された「UNREAL LIFE（アンリアルライフ）」の＃０～＃３の攻略ガイドを掲載します。

<!-- more -->

## ゲーム仕様

### アイテムの使い方

アイテムの使い方が２種類存在する。１つはＡボタン（Ｚキー）から使う行動を選ぶ方法と、もう１つはＺＲボタン（Ｘボタン、または、Ｒキー）押下で使用する方法である。紛らわしいが、設置物への使用かどうかで分類されているようなので、扉や本棚等に対してアイテムを使う場合は前者、小物類（笛等）のアイテムを使う場合は後者と覚えておけば混乱しない。なお、本攻略チャート中では、前者について【赤いビー玉を使う】のように記述するようにしている。

### セーブデータの仕様

チャプターごとにセーブスロットが別で用意されており、新しいチャプターに進んだ時に保存される（該当スロットが既に使われている場合は上書きする）。また、ストーリー分岐地点専用のスロットも１つだけ用意されており、該当の分岐地点直前で自動的に保存される。そのため、任意のチャプターや分岐地点からやり直せるため、マニュアルセーブを使う機会は中断したい時くらいしかない。

## 本編攻略チャート

この攻略チャートは、最小限のアクションでストーリーを進行できるように構築している。そのため、隅々までゲームを楽しみたいという場合は、以下のチャートで示した内容を本筋として沿うのであれば、「調べる」「さわる」等のコマンドを積極的に使って寄り道して構わない。

### ＃０ 初めから

#### １：195番道路

1. 信号機とのイベント会話後に左へ移動し、青い靴を見つけたら【調べる】。それから信号機の指示に従って、左端の電柱に【さわる】。
2. 右へ移動して、信号機を【さわる】。イベント発生後に、右端へ移動する。

#### ２：アパート

1. ガイドに従ってカバンを開き、【青い本】を取り出した後に使用する。
2. フェンスを【ゆする】とモノが落ちてくるので、それを【調べる】。
3. カバンから【赤いビー玉】を取り出し、アパート１階から【階段を上がる】と２階通路の欄干にカラスが移動してくるので、【赤いビー玉を使う】。
4. カバンから【どこかのカギ】を取り出し、アパート２階から【階段を下る】。そして、１階右部屋のドア前に移動し、【どこかのカギを使う】。

### ＃１ 海が見える部屋

#### １：自分の部屋

1. イベントが発生するまで右へ移動する。ガイドに従って目を閉じ、メインメニューから【わたしの考え】に進み、いずれかの項目を選ぶ。
2. メインメニューを閉じた後、部屋の右端にあるエレベーターから【下に行く】。

#### ２：ロビー・カフェテリア

1. 支配人との会話イベント後、カバンを開いて【青い本】を取り出し、支配人に【「先生」について】尋ねてから【青い本を使う】。
2. イベントが発生するまでエレベーターの右手にある従業員用の通路に近づく。ガイドに従って目を閉じ、メインメニューから【おはなししたコト】を選ぶ。
3. メインメニューを閉じた後、エレベーター前に戻り、【カフェテリアへ】移動する。
4. 左から２つ目の照明の右下にある水槽を【調べる】と、シェフのマリモと会話できるようになるので、【「先生」について】尋ねてから、【青い本を使う】。
5. エレベーターでロビーに戻ってから、左端にある来客用の簡易駅へ向かう。

#### ３：来客用の簡易駅・ロビー

1. ペンギンの左横にある看板のポールを２回【ゆする】と、ペンギンが起きるので【お話しする】。続けて、【「幻想図書館」について】も尋ねる。
2. ロビーに行き、支配人に【「電車」について】尋ねてから、右端の従業員用の通路から外に出る。

#### ４：業務用エレベーター・ロッカールーム

1. 左端の小屋（ロッカールーム）に入り、奥のロッカーの右手前の壁の膨らみを【ゆする】とスイッチが出てくるので、その【レバーを下げる】。
2. ３つ並んだスイッチの中央の【レバーを下げる】とイベントが発生する。ガイドに従って目を閉じ、メインメニューから【さわったモノ】を選ぶ。
3. メインメニューを閉じた後、ロッカールームの外に出て、業務用エレベーターから【上に行く】。

#### ５：職人の部屋～来客用の簡易駅

1. ネズミの職人とのイベント会話後、右奥のテレビに【さわる】と電源が付けられるようになるので、【テレビをつける】。その状態でテレビを再び【さわる】。
2. 業務用エレベーターに向かうと転送ドアを使えるようになるので、それを【起動する】。イベントシーン終了後、転送ドアから【自分の部屋に戻る】。
3. エレベーターでカフェテリアまで移動し、シェフのマリモに【「電池」について】尋ねた後、エレベーターからロビー経由で来客用の簡易駅に移動する。
4. カバンから【おおきな電池】を取り出し、電車と看板のポールの間にある何かの装置に【おおきな電池を使う】。左へ進み、電車のドアから【乗る】。

### ＃２ お魚の駅

#### １：魚の駅

{% message color:info %}
※ペンギン（カセリ）の周辺で【エビのビン】を使うと、実績「餌付け」を達成。
{% endmessage %}

1. 左へ進み、階段を通り過ぎた先にある緊急停止ボタンの【ボタンを押す】。
2. 右へ引き返して【階段を上がる】。２階では右へ進んで【階段を上がる】。３階では階段の左側にある乗り越し精算機に【さわる】。その後、乗り越し精算機左下の床面を【調べる】。
3. カバンから【ペンギンコイン】を取り出し、３階から１階まで来た道を戻り、ホームの右へ進んだ先にある自動販売機で【ペンギンコインを使う】。
4. ２階への【階段を上がる】。エビのビンを使いながら、赤いペンギンを右端の茶色いペンギン付近まで誘導し、茶色いペンギンを左端の網がついたクレーン付近まで誘導する。
5. イベントシーン終了後※、階段を使って１階から３階まで移動し、右の改札から【出る】。そのまま右へ進み、階段を上って駅の外に出る。

#### ２：商店街・路地裏

1. 商店街の右端まで移動して自動販売機に【さわる】。次に、自動販売機の左隣にある植木鉢を【左へ動かす】。それから、路地裏に続く道へと【入る】。
2. 転送ドアを【起動する】。次に、右へ進んで犬に近づいてから、左へ引き返して大きな白い花を【調べる】。そして、転送ドアから【自分の部屋に戻る】。

#### ３：カフェテリア～給水所入口

1. 自分の部屋のベッドで起きた後、テレビに近づくとイベント発生（※ミニゲーム機能追加）。
2. エレベーターでカフェテリアまで移動し、シェフのマリモに【「お肉」について】尋ねた後、エレベーターで自分の部屋に戻って、転送ドアから【路地裏へ】向かう。
3. カバンから【ほね付きお肉】を取り出し、路地裏にいる犬に近づくとイベントが自動で発生するので、その上で犬と【お話しする】。
4. 犬より右側にある自転車を【さわる】。それから商店街へ戻り、建物の間にある白いアコーディオンカーテンのような壁を【調べる】と、給水所へのゲートが開くので【入る】。

#### ４：給水所

{% message color:info %}
この場所では、カバンにある【エビのビン】を、カメの誘導に使用する。また、誘導する時は、カメのタンクが空ではないことを確認する（もしくは、カメが給水管に向かった後に少し時間を空けてから、エビのビンを使用する）。
{% endmessage %}

##### １つ目のフロア

カメを右端の排水管へ誘導し、水を吐き出させている間に足場台へ上がる。すぐに左端まで移動して待つと、タンクに乗って反対側へ移動できるので、開いたゲートへ入る。

##### ２つ目のフロア

カメを手前の排水管へ３回誘導してから、はしごを登って高台のスイッチを２回押す。もう一度誘導して水を吐き出させている間に、はしごを登って高台からカメのタンクへ移動する。そのまま反対側まで移動し、開いたゲートから入る。

##### モニタールームと最後のフロア

モニタールームは素通りして右のフロアへ移動し、左から３番目、２番目、１番目、４番目のエビの絵の位置の順に誘導する。

### ＃３ 路地裏とワンちゃん

#### １：路地裏

{% message color:info %}
※犬（ベル）からハンドルを受け取った後に【さわる】と、実績「自慢の毛並み」を達成。
{% endmessage %}

1. 犬（ベル）を笛で誘導するイベントが発生するので、感嘆符マークが出現する場所まで右へ移動させる。犬（ベル）がタカラモノを拾得した後に自分の周辺まで移動させて操作を終了し、【ハンドルを受け取る】※。
2. カバンから【ハンドル】を取り出し、読み取ったキオクの場所に【ハンドルを使用する】。続けて、ワイヤー装置を【しめる】。
3. 転送ドア左横へ移動してから、カバンから【金色のホイッスル】を取り出して使用する。感嘆符マークが出る場所（ガスボンベ左手側のパイプ）まで左方向へ犬（ベル）を誘導すると二階に上がっていく。更に左端まで誘導してはしごを下ろさせる。
4. はしごを登って右へ進み、柄つきの板を調べて【たおす】。次に、隣の建物の植木鉢が見える窓枠の付近まで犬（ベル）を誘導する。それから、板を渡って隣の建物の入口から【入る】。
5. 左にある小さい植木鉢を【さわる】。次に、読み取ったキオクの場所を調べて【レバーを下げる】。部屋が明るくなった後に、入口右手の【レバーを下げる】。そして、左奥の【レバーを上げる】。
6. 部屋を出て来た道を戻ってワイヤー装置を【ゆるめる】。次に、犬（ベル）をパイプ経由で屋上の装置まで誘導する。その後に、ワイヤー装置左隣の【はしごを登る】。屋上に登ってからは、右へ進む。

#### ２：幻想図書館

##### ２Ａ：エントランス・バルコニー

1. 右に進んだ先にある扉から館内へ入館するとイベント発生。次に、左端にある２階への【はしごを登る】。それから、右手の転送ドアを【起動する】。続いて、その先にある出口から外へ【出る】。
2. 左に進み、りんごの木を【ゆらす】。次に、館内を経由して１階入口から外へ出て、かごが付いた台を１回【左に動かす】。それから、バルコニーへと再び行き、りんごの木を【ゆらす】。
3. バルコニーから館内に戻って、出口の右手にある【レバーを下げる】。次に、１階入口から外に出て、かごが付いた台を２回【左に動かす】。それから、館内へと入り直して、右へ進む。

##### ２Ｂ：書架・休憩室

1. 右へ進み、青い本棚から【赤い本】を入手後、カバンから【赤い本】を取り出し、手前の赤い本棚まで戻って【赤い本を使う】。動いた本棚の上にはしごを使って移動し、【黄色い本】を入手する。
2. 本棚から【赤い本】を回収して書架の奥へ進み、カバンから【黄色い本】を取り出して、黄色い本棚で【黄色い本を使う】。その後、右手側のはしごを登って、カバンから【赤い本】を取り出し、細い本棚に【赤い本を使う】。
3. 右へ進んで赤い服の警備員を【調べる】。左へ戻ってはしごを下り、右へ進んでイベントを見る。それから、付近の警備員のライトに当たって入口に戻る。
4. カバンから【黄色い本】を取り出して書架に戻り、一番目の黄色い本棚で【黄色い本を使う】。隠し扉から休憩室に入り、右手前ロッカーの左にあるイスを【さわる】。その後、休憩室を【出る】。

##### ２Ｃ：バルコニー・休憩室・書架

{% message color:info %}
※【ロッカーのカギ】を入手した後に同じ警備員を【調べる】と、実績「もふもふ愛好家」を達成。
{% endmessage %}

1. 黄色い本棚から【黄色い本】を回収し、受付２階の【レバーを上げる】。バルコニーに出てから右へ進み、マグカップを【さわる】。その後、館内に戻って受付２階の【レバーを下げる】。
2. カバンから【黄色い本】を取り出して書架の奥へ進み、上に警備員がいる黄色い本棚で【黄色い本を使う】。左手側のはしごを登り、その警備員を後ろから【調べる】※。それから、はしごを下りて付近の警備員のライトに当たって入口に戻る。
3. カバンから【黄色い本】を取り出して書架に戻り、一番目の黄色い本棚で【黄色い本を使う】。休憩室に入って、カバンから【金色のホイッスル】を取り出し、右手前ロッカーへ【入る】。それから、金色のホイッスルを使い、警備員が居なくなった後にロッカーから【出る】。
4. カバンから【ロッカーのカギ】を取り出し、左奥のロッカーに【ロッカーのカギを使う】。次に、開いたロッカーへ【入る】。その後は、休憩室から【出る】。
5. カバンから【青い本】を取り出し、書架の一番奥へと進み、金色の本棚に【青い本を使う】。その後、エレベーターで【下に行く】。

##### ２Ｄ：地下書庫

右へ進み、ホワイトボード右隣にある新聞紙を【さわる】とイベント発生。その後に、新聞紙の【字を読む】。読み終わってから、エレベーターで【上に行く】。
