## 作品概要

記憶喪失の少女ハルは気が付くと、意思を疎通できる信号機がいる不思議な夜の街中にいた。触った無機物の記憶を読み取る「サイコメトラー」の能力者であることが分かった彼女は、自分の記憶の手がかりとなる「先生」を探し出すために旅に出る。これは、読み取った過去の記憶を頼りに謎を解きながら、少しづつ世界の真実へと近付いていく、少女ハルが主人公となるアドベンチャーゲーム。

### 登場人物

プレイアブルキャラクターの「ハル」を始め、物語のキーパーソンとなる「先生」、ハルと旅を共にするＡＩ信号機「195」、旅の宿「くじら」では、ロビーにいる支配人、カフェテリアのシェフでマリモの「マリー」、職人のネズミ「シュタイン」、道中では、電車を運転できるペンギンの「カセリ」、犬の「ベル」、ガイコツの「トクロ」など個性豊かな人物が登場する。

### ゲーム本編

ゲーム本編は、探索パートを中心としたＡＤＶパートを含むチャプターが８つで構成され、プレイヤーの行動次第で４つエンディングに分岐する。探索パート中では、プレイヤーはハルを操作すること以外に、メインメニューや設定メニューを開ける。

#### 探索パート画面

ハルを探索させたり、アイテムに対して行動を選べる画面。

##### 調べる

Ａボタン（Ｚキー）押下で、モノに対して行うアクションを選べる。始めは「調べる」のみだが、ストーリーの進行状況やモノの状態に応じて、行動の選択肢が増える。なお、調べられるモノにハルが近付くとサークル状のマーカーが自動で表示されるが、モノによってはＡボタンを押すことで初めてアクションを選べるようになるものがいくつか存在する。

{% gallery review-unreal-life command.webp '調べるコマンド' 719x404 %}
ただ調べるだけではなく、「さわる」「覚える」「動かす」「使う」等もできるようになる
{% endgallery %}

##### かばんを開く

ストーリー中で獲得したアイテムは、使い捨てのものではない限り、かばんに全て保管される。Ｒボタン（ＲＢボタン、または、Ｅキー）押下で、かばんからアイテムを一つ選んで取り出せる。

{% gallery review-unreal-life bag.webp 'かばんの中身' 719x404 %}
本編終盤になると沢山のアイテムが入っていて、想像以上に高い収納力がある
{% endgallery %}

##### アイテムを使う

かばんから取り出したアイテムを、ＺＲボタン（Ｘボタン、または、Ｒキー）押下で使用する。ただし、全てのアイテムに対応しているわけではなく、調べるアクションの中から「使う」選択肢を経由して間接的に使わなければならないものがある。

#### ＡＤＶパート画面

登場人物の会話やハルの回想等のイベントシーンで使われる、一般的なアドベンチャーゲームの画面。しかし、ウインドウ非表示やスキップモード、オートモード等の近代的な機能は備えていない他、クイックセーブ等の中断機能もなく、メッセージを読ませるだけの最低限の機能になっている。

{% gallery review-unreal-life adv_part.webp 'ＡＤＶパート' 719x404 %}
本作で最も力が入っているといっても過言ではない、美味しそうなハムエッグトースト
{% endgallery %}

#### メインメニュー

探索パート中に、Ｌボタン（ＬＢボタン、または、Ｑキー）押下でメインメニューを開ける。ただし、最初から全解放されているわけではなく、ストーリーの進行でメニュー項目が増える仕組み。そのため、メニュー項目がない最序盤はメインメニューを使えない。

##### わたしの考え

最初に解放されるメニュー項目。ハルが見たことや聞いたこと、感じたこと等を、彼女自身がどのように考えているかをプレイヤーが見られる機能。ストーリー進行だけではなく、モノをさわったり、アイテムを手に入れたり、ハルを操作した時も項目が増える。

##### おはなししたコト

２番目に解放されるメニュー項目。ＡＤＶパートのバックログを見返すための機能で、195とハルが話していることや聞いたことを、ログとして保存する仕様。そのため、演出で文章が読みにくかった場合でも、これを使えば何と書かれていたかが後から分かる。なお、彼女らが記憶を思い出したり忘れたりすると、内容が変化する。

##### さわったモノ

最後に解放されるメニュー項目。ハルが過去に読み取った全ての記憶を、モノごとに195との会話付きで見返せる便利な機能。ちなみに、見返す度に「おはなししたコト」の会話ログに追加される。

### ミニゲーム「VOLTA」

対戦型シューティングゲームで、旅の宿「くじら」の自分の部屋にあるゲーム機を使って、195と戦える。開始前に５枚の技カードデッキをコスト制限内で構築し、戦闘中はチャージゲージが溜まっていれば左から順番に技を発動でき、相手に攻撃を当てて体力を０％にした方が勝ちとなる。そして、勝つと新しい技カードを手に入れられる。また、始めは弱い195も、ストーリー進行に応じてレベル上限が解放され、勝つとレベルが上昇して強化される。なお、強力な必殺技カードを手に入れられる隠しコマンドもある。

{% gallery review-unreal-life volta.webp 'ミニゲームのデッキ構築' 719x404 %}
隠しコマンドで手に入れた「クロックアップ」と「脆刃」があれば確実に勝利できる
{% endgallery %}

### 設定

タイトル画面とゲーム本編の探索パート中の両方から、ゲームの設定機能を呼び出せる。音量設定や言語設定、画面表示設定の基本的な項目に加え、視覚サポートや画面フィルタの調整も可能。ゲーム本編終盤には赤色を使った表現が多くあり、それを強く強調する演出に変えたい場合は、視覚サポートの「赤色を目立たせる」をＯＮに変えておこう。
なお、このゲームではタイトル画面に戻る機能がないため、別のセーブデータを読み込み直したい場合、設定から終了させた後に再起動させる手間が必要になる。

## 作品評定

### 評点

{% message color:info %}
82点（優/A-ランク）
{% endmessage %}

ひと昔前のドット絵による粗い表現や煩わしい操作感があるレトロなＰＣゲームを好み、ホラー風味の演出とほの暗いストーリー展開でも気にしない人にはオススメできる作品。

#### 評点の内訳

{% message %}
美少女ゲームと採点基準が異なることに注意してください。
{% endmessage %}

### コメント

#### コストパフォーマンス

本編に加え、やりこみ要素のミニゲームが遊べてお得感がある。隠し要素まで見れば満足できるボリューム感だが、この価格帯でもフルボイスゲームがあることを考えると、少し物足りないところ。

#### ゲームバランス

アイテムを使う操作や画面を閉じる操作に割り当てられたキーが複数あり、キーボード操作だと間違いやすくストレスを感じる操作性。マウスだけでも一連の操作が可能に調整されていることは良い点。

#### 世界観

物語のテーマとしてはありきたりで独自性に欠ける。一方で、少し過剰なところもあるが色の表現を上手く使った幻想的で、信号機等と意思疎通できる非現実的な世界観を上手く表現できている。

#### ゲーム性

ストーリーを進めていく上で、内容と無関係な謎解きギミックがところどころに仕掛けられており、本筋から外れたくないプレイヤーの意志を削いでいて、面白さや満足感を損なわせていたことが残念。

#### 音楽

プレイ中に不快を感じさせず、盛り上げるべきところは抑えていて、世界観も壊さない良いＢＧＭが揃っていた。エンディング曲もストーリーに沿った内容だった。
