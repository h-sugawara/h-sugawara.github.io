2025年11月に Steam と Switch で発売された、ハチャメチャ代筆コメディアドベンチャーゲーム「代筆屋ワールドワード」をレビューします。

## 作品概要

ウィルズベリー共和国の首都にある代筆屋「ワールドワード」でバイトをし始めた、大学生のカケル。とてつもなく気分屋な彼は、依頼者の代筆で書く手紙を、ポテトを食べた手で汚したり、コーヒーを零したりしたまま、締めの言葉をルーレットで決めてしまったりとやりたい放題。初秋、大学の休みが明けるまでの短い間、ハチャメチャな彼が周囲を巻き込むコメディ一辺倒なアドベンチャーゲーム。

### 登場人物

プレイアブルキャラクターの「カケル」を始め、ワールドワードの店長と、先輩バイトで大学の後輩でもある「モノ」、メインストーリーでは「ジニー」「みう」「しのぶ」「Ⅴー６号」など様々なキャラクターが登場する。

### ゲーム本編

ゲーム本編は、一般的なＡＤＶのようにオープニングからエンディングまでをひと塊でプレイする形式ではなく、５話に分割された中から１つを選んでプレイする形式。それぞれのストーリー中では、ＡＤＶパートと取材パート（第１話を除く）を中心に進行し、終盤で代筆パートに入る画面構成である。

#### ＡＤＶパート画面

依頼を受ける時や取材をする時など登場人物間での会話に使われる、一般的なアドベンチャーゲームの画面。ワードノートが使用可能になっている場合は、メニューの「WORD」から集めたワードの一覧を確認できる。他にも「SAVE」「LOAD」「CONFIG」「EXIT」など基本的な機能は備えているが、オートモード等の拡張機能はない。ストーリー中に選択肢なども無いため、もっぱら会話を読むための画面である。

モノちゃんを始め、このゲームに出てくる女の子はみんな可愛い
{% endgallery %}

#### 取材パート画面

ワードノートが使えるメインストーリー第２話以降で解禁される、代筆で使うワードを集めるパート。マップで建物や場所（自宅・職場・ゲームセンター・あざらし百貨店・メイドカフェ）に移動し、取材したい人物を選ぶと、ＡＤＶパート画面へ移行する仕様。なお、あざらし百貨店で働いているⅤ－６号と、メイドカフェで働いているしのぶの２名については、会話以外に買い物もできるようになっている。

##### あざらし百貨店

様々なアイテムや家電が売っている百貨店。選んだストーリーによってラインナップが異なる。ジュークＢＯＸや薄型テレビ、低価格パソコン等の家電は買うと自宅に設置される。また、これらは一度でも購入するとラインナップから消え、他の家電に置き替わる。特に、薄型テレビは放送中の番組から単語を集められるので、実績のために全ワードコンプリートする場合は購入必須。

{% gallery review-ghostwriter-workshop department_store.webp 'あざらし百貨店の品揃え' 719x404 %}
キーアイテムの「つまらないもの」はこの店で購入できる
{% endgallery %}

##### メイドカフェ

注文したメニューの種類に応じて、ストーリー終了時に給料が上がる仕組みになっている。とはいえ、例えばコーヒーを２回注文しても１種類とみなされるので、チート行為はできない。しのぶとは初めて話すときに注文が必要になるが、コーヒーやフライドポテトは代筆パートで手紙を汚してしまうため、実績のために避けたい場合は、フルーツパフェの注文がオススメ。ちなみに、オムライスやドンペリには専用ＣＧがあるので、回収のために一度は注文しておきたい。

{% gallery review-ghostwriter-workshop maid_cafe.webp 'メイドカフェのメニュー' 719x404 %}
なぜかドンペリがメニューのラインナップにあるメイドカフェ
{% endgallery %}

#### 代筆パート画面

依頼を受けた文章を代筆する、各ストーリーの最後を構成する画面。プレイヤーは、締めの文章を除いて、主人公が記述するテキストを眺めるだけで良い。代筆する文書は２枚書く仕様のため、締めの文章を書く機会は２回訪れる。ルーレットは、その機会ごとに３度回すことになる。設定で代筆のやり方を変更すれば、任意にワードを選べるようになるが、どちらでもストーリーの大筋に差は出ない。なお、取材パートで最低限のワードを集めないと、代筆パートに移行できないようになっている。

目押しで普通の代筆屋を目指すのも良いが、雑に押してハチャメチャな文章を作った方が面白い
{% endgallery %}

### エントランス画面

タイトル画面で「START」を押下した時に表示される画面。メインストーリー選択、人物情報の閲覧、エンドレスモードの３つから選べる。

#### メインストーリー選択画面

エントランス画面で「メインストーリー」を押下した時に表示される画面。最初から選べるのは、第１話に相当するストーリーのみで、ストーリーを見終わるごとに次のストーリーが解禁されていく。第５話まで見終わると、エントランス画面の「エンドレスモード」とエクストラ画面の「前日譚ストーリー」が解放される。ちなみに、給料や所持金、昇給額はシステムデータとして保存されており、ストーリーをプレイする度にこれらが上昇していく仕様になっている。

#### ＷＯＲＬＤ　ＷＡＶＥ画面

メインストーリー中に知り合った人物の各種情報（性別・身長・星座・趣味等）が記載されたプロフィールを閲覧できる。メインストーリーの取材パート中に「つまらないもの」を購入し、登場人物のうち誰かに渡すと、プロフィールのカギポストの部分がアンロックされる。なお、「つまらないもの」はストーリープレイごとに１回しか購入できないため、全員分を閲覧するためには、何度か周回する必要がある。

{% gallery review-ghostwriter-workshop profile.webp 'プロフィール' 719x404 %}
メインストーリーに登場する人物たちの本編では語られない情報が得られる
{% endgallery %}

#### エンドレスモード

取材パートなしで代筆パートのみを永遠に繰り返すモード。メインストーリー中に依頼をしなかった登場人物たちや、そもそも登場しなかった人物からも代筆の依頼を受けられる。使えるワードは最初から全て回収済みになっていて、思う存分にルーレットを堪能できるのが醍醐味。ただし、このモードに登場する人物は決まっているため、お客が一巡すると同じ依頼内容を順不同で繰り返すことになる。

### 設定画面・言語画面

設定画面は、タイトル画面から直接、または、ゲーム本編中から「CONFIG」メニュー経由で呼び出せる。機能としては、ＢＧＭとＳＥの音量設定、画面表示設定の基本的な項目に加え、文字速度の変更の他、珍しく決定ボタンとキャンセルボタンの入れ換えができる。また、代筆のやり方をデフォルトのルーレットからチートに変更することもできる。目押しが大変なので、一部の実績を達成する際にお助け機能として使える。なお、言語設定は設定画面の項目に含まれず、タイトル画面の「LANGUAGE」から専用画面を開いて変更する必要がある。

### エクストラ画面

クレジット画面、アルバム画面、トロフィー画面、前日譚ストーリーのプレイ画面の４つで構成される。
アルバム画面は、メインストーリーのプレイ中に回収したイベントＣＧを閲覧できるモードで、トロフィー画面は、達成した実績の一覧を見る（Steam の実績と同期されている）モードで、前日譚ストーリープレイ画面は、全編クリア後にアンロックされるモードである。

### コメント

#### コストパフォーマンス

やり込み要素が登場人物のプロフィール埋めやエンドレスモード程度で、メインストーリーも２～３時間程度で終わる短さのため、客観的な側面での物足りなさはあるが、コメディ調になっていて主観的な側面では満足感を得られるため、買って損はない。

#### ゲームバランス

目的地に移動し、登場人物と会話して、代筆でルーレットを回すという、洗練されたシンプルな遊びやすさで、誰でも簡単にプレイできるように設計されているため、反射神経やゲーム文化への慣れなども不要で、操作が簡単でストレスもない。

#### 世界観

ルーレットを回して締めの言葉を決める代筆屋という設定は、目の付け所が良く、非常に高い独自性を持っていると評価できる。しかしながら、没入感の観点では、ストーリーのテーマから考えると、異世界風にする価値を付加しきれていなかったことが残念。

#### ゲーム性

手紙の内容はルーレットによって変わるため、プレイする度にランダム性がある程度確保されており、その点では面白さがある。その一方で、ルーレットを回すこと自体にマンネリ化の要素があるため、引き伸ばさずに全５話で短くまとめたのは良い判断だったと思われる。

#### 音楽

可も不可もなく無難だが、粒ぞろいの良い曲が揃っていた。しかしながら、少し気になった点で言えば、音質がくぐもって聞こえることである。クリアな音質であればもう少し評価が良かっただろう。
