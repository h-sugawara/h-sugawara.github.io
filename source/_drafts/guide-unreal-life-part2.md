2020年5月に Switch で、同年11月に Steam 版、2022年3月に iOS/Android 版が発売された「UNREAL LIFE（アンリアルライフ）」の＃４～＃８の攻略ガイドを掲載します。

<!-- more -->

{% message color:info %}
検索等から辿り着いて本ゲームの＃０～＃３の攻略が必要な方は、{% post_link guide-unreal-life-part1 '前編' %}をご覧ください。
{% endmessage %}

## 本編攻略チャート

この攻略チャートは、最小限のアクションでストーリーを進行できるように構築している。そのため、隅々までゲームを楽しみたいという場合は、以下のチャートで示した内容を本筋として沿うのであれば、「調べる」「さわる」等のコマンドを積極的に使って寄り道して構わない。

### ＃４ 青い本

#### １：カフェテリア～絵の壁

1. 自分の部屋からエレベーターでカフェテリアまで移動し、左端のソファーを【調べる】とイベント発生。ガイドに従って【青い本】を使用する。
2. 再びエレベーターを使って自分の部屋まで戻り、転送ドアから【路地裏へ】移動して、屋上にいる犬と【お話しする】。
3. 右へひたすら進み、幻想図書館の入口も通り過ぎ、転送ドアを見つけたら【起動する】。更に先へ進み、白いキャンバス手前にある看板の【字を読む】。そして、キャンバス右手にいるガイコツと【お話しする】。
4. 幻想図書館入口前まで移動し、かごが付いた台周辺に落ちているりんごを【覚える】。白いキャンバスの前に戻ってきて、カバンから【お絵描きブラシ】を取り出して使う。イベントを見た後に、【お絵描きブラシ】をキャンバスに再び使ってから、右へ進む。

#### ２：幻想美術館

##### ２Ａ：展示回廊・倉庫

1. 右へ進み続けて入館し、奥にある転送ドアを【起動する】。入り口側に戻って、上りエスカレーターに【乗る】。それから、２階の展示回廊に【入る】。
2. １つ目の部屋はそのまま右へ進み、２つ目と３つ目の部屋は階段を上がって右へ進んで、出口から退場する。下りエスカレーターは素通りして右へ行き、突き当たりの出入口から倉庫へ【入る】。
3. 出入口の左右に置いてあるキャンバスを両方とも【さわる】。転送ドアを起動し、それを使って自分の部屋を経由して幻想美術館に戻る。

##### ２Ｂ：館外・展示回廊・館内・倉庫

{% message color:info %}
※絵の壁へ行ってガイコツ（トクロ）と【お話しする】と、実績「絵筆のソウル」を達成。１回目にミニゲームの話が出た場合は、もう一度話しかけること。
{% endmessage %}

1. 館外の看板前まで行き、その絵を【覚える】。館内２階の展示回廊へ行き、１つ目の部屋の下のキャンバスに【お絵描きブラシ】を使った後、入口へ逆走し途中退出口から地下１階に出る。
2. 左の立ち入り禁止ゾーンへ入る。奥にある機械の絵が「月が左、星が下、太陽が右」の配置になるまでボタンを押し、その状態の絵を【覚える】。
3. 展示回廊に戻り、１つ目の部屋は先ほど絵を書いた方を進み、２つ目の部屋の上のキャンバスに【お絵描きブラシ】を使ってから進む。３つ目の部屋では上のキャンバスに【さわる】。そして、右へ進み出口から退場する。
4. 出口左手の非常口のマークを【覚える】。再び展示回廊の３つ目の部屋まで進み、上のキャンバスの右横で【お絵描きブラシ】を使った後、出口※から倉庫の奥へ移動する。

### ＃５ 旅立ち

#### １：幻想美術館倉庫・電車内

{% message color:warning %}
※１：ミニゲームをＬｖ６（実績「ジェノサイド」達成）にしなければ、以降は最大Ｌｖが７以上にならないため、全ての実績を達成する場合は電車出発前に済ませておくこと。
{% endmessage %}

{% message color:info %}
※２：ベッドで１回目の【寝る】から２回目の【寝る】までの間に、ベッド右の食品収納ボックスを【調べる】と実績「用意周到」を、ペンギン（カセリ）と２回【お話しする】と１回目に実績「ヘンな夢」、２回目に実績「凄腕技師」を達成。
{% endmessage %}

1. 自分の部屋から転送ドアで【幻想美術館倉庫へ】移動し、電車が泊まっているホームへ向かう※１。
2. 電車内※２では、ゼロまたはペンギン（カセリ）のいずれか１名以上と【お話しする】と、ベッドで寝られる。これを２回繰り返すと、深夜にゼロと会話するイベントが発生。その後、両者と会話してからベッドで【寝る】。

#### ２：幻の駅～教室・195番道路

{% message color:danger %}
プレイヤーの行動でエンディングが分岐する。エンディング「ある少女のデザイア」に進むには「エンディング分岐１」を、エンディング「ある少女のパラドクス」に進むには「エンディング分岐２」を、次のチャプターに進むには「ストーリー続行」を参照すること。
{% endmessage %}

##### エンディング分岐１

1. ホームの左側へ行き、その先にあるトラックを【調べる】。そこから更に左へ進み、踏切の横にある【階段を上がる】。階段を上ってからは、イベントシーンを見ながら右へ移動する。
2. 教室左奥にいる先生の呼びかけに答えて左へ移動する。

##### エンディング分岐２

1. ホームの左側へ行き、その先にあるトラックを【調べる】。そこから更に左へ進み、踏切の横にある【階段を上がる】。階段を上ってからは、イベントシーンを見ながら右へ移動する。
2. 教室左奥にいる先生の呼びかけには答えず、足元に出ているガイドが指す右方向へ移動し続ける。

##### ストーリー続行

1. ホームの右側へ移動し、地面が赤く光っている場所を【調べる】。ホームの左側へ行き、その先にあるトラックを【調べる】。そこから更に左へ進む。
2. カバンから【赤いビー玉】を取り出し、踏切の横にある【階段を上がる】。階段を上ってからは、イベントシーンを見ながら右へ移動する。
3. 教室左奥にいる先生の呼びかけには答えず、足元に出ているガイドが指す右方向へ移動し続ける。
4. 195番道路に戻ってきた後、踏切の左手側にある電柱に【さわる】。

### ＃６ 空飛ぶクジラ

#### １：195番道路・通学路

{% message color:info %}
※１：ロビー左手にある来客用の簡易駅へ向かい、ホーム左奥まで進むと、実績「青」を達成。
※２：踏切右にある枯れ木を【調べる】と、実績「気になる木」を達成。
{% endmessage %}

1. 自分の部屋からエレベーターでロビーへ行き※１、ロビー左手側にあるステンドグラス下のドアから【入る】。アパートから195番道路に出て左へ進む。
2. 踏切の前でイベントが発生するので、ガイドに従って目を閉じ、メインメニューから【おはなししたコト】に進み、一番古い会話を確認する。
3. メインメニューを閉じてから、踏切※２の中に【入る】。その後は、通学路を右へ移動する。

#### ２：学校

##### ２Ａ：校舎内

1. 玄関から校舎内に入り、１階右奥の【レバーを下げる】。左手前の階段まで戻り、２階に上がって左手にある美術室の奥からバルコニーへ出て、手前の【レバーを下げる】。更に右へ進むと美術室内に戻されるので、そこから階段を使って３階へ上がる。
2. ３階を左奥へ進み、【レバーを下げる】。右手前に戻り、像のない中央の台座を調べて【字を読む】。それから、左の像を右へ、右の像を左へ動かし、完成した中央の像を【覚える】。
3. ２階の美術室へ戻り、カバンから【お絵描きブラシ】を取り出し、手前の真っ白なキャンバスに使う。それから、バルコニーに出て、奥の【レバーを下げる】。その後、美術室内に戻り、階段を使って屋上へ出る。

##### ２Ｂ：屋上・理科室

1. カバンから【金色のホイッスル】を取り出して使用し、犬を屋上の階段室の屋根まで誘導する。次に、カバンから【エビのビン】を取り出して使用し、カメを階段室の屋根に繋がっているパイプ右横付近まで誘導する。
2. 階段室の扉の左隣へ移動し、カバンから【金色のホイッスル】を再び取り出す。犬を時計台屋根の光っている所まで誘導するとカギを拾うので、自分の周辺まで近付けてから操作を終了して【カギを受け取る】。
3. カバンから【理科室の鍵】を取り出し、屋上から校舎２階の階段右にある理科室前へ移動し、扉に【理科室の鍵を使う】。そして、鍵を開けた理科室に【入る】。
4. 右奥にある汚れた黒板を調べて【さわる】。その後、黒板のすぐ左手の扉から出て、廊下の突き当たり付近にある【レバーを下げる】。それから、来た道を戻って屋上に引き返す。

##### ２Ｃ：屋上

{% message color:info %}
※階段室を素通りして時計台の屋根で降り、左端まで進むと、実績「茜」を達成。
{% endmessage %}

1. カバンから【金色のホイッスル】を取り出して使用し、犬を屋上右端のパイプから２階の動く水管がある場所へ誘導する。それから、笛を使って犬を誘導し、動く水管を右から２番目の位置に動かす（水管を一度左端に移動させ、犬を少し通り過ぎたところでターンさせて４回右へ移動させる）。
2. カバンから【エビのビン】を取り出して使用し、カメを屋上右端の排水管へ誘導する。水を吐き出させている間に、伸びてきた花のはしごを使って塔屋の屋根で待機する。
3. カメのタンクに乗った後、階段室※の屋根を横切るところで降りる。そして、階段室の屋根右手側にある【はしごを下りる】。

### ＃７ 最後の廊下

{% message color:danger %}
ここでエンディングが分岐する。エンディング「ある少女のパラノイア」に進むには「エンディング分岐」を、エンディング「ある少女のアンリアルライフ」に進むには「ストーリー続行」を参照すること。
{% endmessage %}

#### エンディング分岐

回想シーンを見ながら、廊下を右へ進み続ける。突き当たりまで来たら、教室の扉から【入る】。その後は何もせずに学校を出て、通学路の踏切へ【入る】。

#### ストーリー続行

##### １：学校

{% message color:info %}
※１：踏切上のカラスと【お話しする】と、実績「カラスさんの友達」を達成。
※２：踏切右の先生と【お話しする】と、実績「執念」を達成。
※３：踏切右の枯れ木を【調べる】と、実績「曖昧な木」を達成。
{% endmessage %}

1. 回想シーンを見ながら、廊下を右へ進み続ける。突き当たりまで来たら、教室の扉から【入る】。
2. ２階の理科室へ行き、右奥の汚れた黒板を２回【さわる】。それから、学校を出て通学路の踏切から195番道路へ移動し※１～３、くじらに戻る。

##### ２：カフェテリア・職人の部屋・路地裏・魚の駅

{% message color:info %}
※１：条件を満たしている時に限り、自分の部屋でミニゲームに関する全ての実績を達成できる。
※２：幻想美術館倉庫に行き、ホーム奥にいるマリモに話しかけると、実績「面影」を達成。
※３：２階右端で仲良く寝ているペンギンのところまで行くと、実績「おつかれさま」を達成。
{% endmessage %}

1. ロビー※１からエレベーターでカフェテリアに行く。シェフのマリモとの会話イベントを経た後、ロビー右端の従業員用の通路から外に出る。業務用エレベーターから【上に行く】と、ネズミの職人との会話イベント発生。
2. 路地裏で犬との会話イベント後※２に、商店街に出て魚の駅へ行く。改札※３を通って１階のホームまで下りると、ペンギン（カセリ）との会話イベント発生。くじらに戻ってくるので、来客用の簡易駅からロビーへ向かうと、支配人との会話イベント発生。

### ＃８ 現実へ

アパートから195番道路に出て左に進み、先生に【現実へ帰る】ことを伝えると、信号機との会話イベントが発生。かばんから【青いクツ】を取り出して使う。

## ミニゲーム攻略

### 必勝法

1. 左から「クロックアップ」「脆刃」「ノーマルショット」×３（コスト１のカード３枚であれば何でも可）でセットする。
2. 相手の攻撃を避け続け、「クロックアップ」と「脆刃」の両カードのチャージが溜まるのを待つ。
3. 「クロックアップ」を発動し、重ねて「脆刃」を発動させた状態で、相手の攻撃に当たらないように避けながら突撃し、脆刃を当てて相手の体力を０％にする。

### クリア実績と報酬

勝利する度に解放済み最大Ｌｖを超えない限りは１つ上がり、実績と報酬を獲得できる。

| レベル | 実績               | 報酬                       |
|:------:|:-------------------|:---------------------------|
|   １   | Lv1 読めないゲーム | なし                       |
|   ２   | Lv2 慣れ           | レフトシフト、ライトシフト |
|   ３   | Lv3 柔軟性         | ライトニングショット       |
|   ４   | Lv4 模索           | スリーウェイショット       |
|   ５   | Lv5 学習機械       | ディレイショット           |
|   ６   | Lv6 ジェノサイド   | バックシフト               |
|   ７   | Lv7 兵器           | チャージ２                 |
|   ８   | Lv8 最適解         | なし                       |

### 隠しコマンド

ロゴが中央に表示されたタイトル画面中で下表のコマンドを入力すると、カードが入手できる。

|     コマンド     | 入手カード     | 発動時効果                         |
|:----------------:|:---------------|:-----------------------------------|
| 上上下下左右左右 | バースト       | 追尾型の弾幕攻撃                   |
| 上右下上上下右上 | ビーム         | 広範囲でスタンさせる攻撃           |
| 左上右上下下下下 | クロックアップ | 相手の動きを鈍化                   |
| 左右右右下上上右 | 雷刀           | 高火力近接攻撃                     |
| 左右下右下上右右 | チャージ４     | 体力を５０％消費＋４つ分チャージ   |
| 下上下左右右左下 | 脆刃           | 体力を９９％消費＋一撃必殺近接攻撃 |
